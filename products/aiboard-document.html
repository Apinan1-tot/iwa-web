Iwa AiBoard คืออะไร

Iwa AiBoard คือจอแสดงผลอัจฉริยะแบบ Interactive Display ชนิด All-in-One ออกแบบมาสำหรับห้องเรียน ห้องประชุม และการนำเสนองาน มาพร้อมหน้าจอสัมผัสความละเอียดระดับ 4K รองรับทั้งระบบปฏิบัติการ Windows และ Android พร้อม AI Camera และซอฟต์แวร์ Whiteboard ในตัว ช่วยให้การสอนและการประชุมเป็นไปอย่างราบรื่นในเครื่องเดียว

จุดเด่นของสินค้า

  • 4K Ultra HD Touch Screen — หน้าจอสัมผัสความละเอียดสูงระดับ 4K
  • Multi-Touch — รองรับการสัมผัสพร้อมกันสูงสุด 20 จุด
  • Anti-Glare + Toughened Glass — กระจกนิรภัยกันแสงสะท้อน ความแข็งระดับ Mohs-7
  • Dual OS — สลับใช้งานได้ทั้ง Windows และ Android
  • AI Camera — กล้องอัจฉริยะสำหรับการประชุมและเรียนออนไลน์
  • Multi-Screen Share — แชร์หน้าจอได้พร้อมกันหลายเครื่อง
  • Whiteboard Software — ซอฟต์แวร์กระดานอัจฉริยะในตัว
  • NFC & Fingerprint — ปลดล็อกด้วย NFC และลายนิ้วมือ
  • Bluetooth 5.2 / Wi-Fi 6 — เชื่อมต่อไร้สายความเร็วสูง
  • รองรับ OPS PC — เสียบชุดคอมพิวเตอร์ OPS ใช้งานได้ทันที
ALL-IN-ONE

8-in-1 ครบในเครื่องเดียว

Whiteboard + Projector + TV + PC + Projection Screen + Set Top Box + Speaker + Advertising Machine — รวมฟังก์ชันของอุปกรณ์ 8 ชนิดไว้ในจออัจฉริยะเครื่องเดียว ลดความยุ่งยากและพื้นที่การติดตั้ง

ใช้ทำอะไรได้บ้าง

  • การเรียนการสอนแบบอินเตอร์แอคทีฟในห้องเรียนและห้องประชุม
  • เปิดไฟล์นำเสนอ PowerPoint / Word / Excel รวมถึงไฟล์ภาพ เสียง และวิดีโอผ่าน USB
  • แสดงหน้าจออุปกรณ์ที่เชื่อมต่อพร้อมกันได้สูงสุด 9 อุปกรณ์ (Multi-Screen Share)
  • เขียน วาด และนำเสนอบนกระดานอิเล็กทรอนิกส์ (Whiteboard) แบบสัมผัสพร้อมกัน 20 จุด

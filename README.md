# IWA Rich U D — Company & Product Catalog

เว็บไซต์บริษัท ไอว่า ริช ยู ดี จำกัด สำหรับแนะนำบริษัท บริการ อบรม/สัมมนา และแสดงรายละเอียดสินค้า/สื่อการเรียนรู้

เว็บไซต์เป็น Static single-page — ไม่ต้อง build สามารถเปิด `index.html` ได้โดยตรง หรือรัน:

```bash
python3 -m http.server 8000
```

## โครงสร้าง

- `index.html` — หน้าเว็บไซต์ทั้งหมด
- `assets/css/style.css` — design system เดิมของเว็บไซต์
- `assets/js/app.js` — rendering สินค้า บริการ อบรม และหน้ารายละเอียดสินค้า
- `assets/img/` — รูปบริษัท บริการ และสินค้า

## การเปลี่ยนแปลง

- เอาระบบตะกร้าสินค้าออก
- เอาระบบ Checkout / PromptPay / ชำระเงินออก
- เอาระบบติดตามออเดอร์ออก
- สินค้าเหลือเป็น Catalog สำหรับดูรูป ชื่อ ระดับ และรายละเอียด
- กด `ดูรายละเอียดสินค้า` เพื่อเปิดรายละเอียดสินค้าแบบ Modal
- หน้า `ติดต่อเรา` เหลือเฉพาะข้อมูลบริษัทและข้อมูลสำหรับการติดต่อ
- ไม่มีการเก็บ cart/order ใน localStorage และไม่มีการส่งคำสั่งซื้อออนไลน์
